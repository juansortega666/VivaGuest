## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Registry de npm → repo | Un paquete es código ejecutable en la máquina de quien instala y en el build |
| Código de prueba → `service_role` | Los helpers de test necesitan saltarse la RLS para sembrar |
| Usuarios semilla → base compartida | Los usuarios `e2e.*` viven en la misma base que el desarrollo |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-SC | Tampering | Instalaciones de npm de toda la fase | mitigate | `slopcheck` no disponible ⇒ todos `[ASSUMED]` ⇒ checkpoint bloqueante humano en la tarea 1, con verificación de repo de origen y ausencia de `postinstall` en npmjs.com. No auto-aprobable |
