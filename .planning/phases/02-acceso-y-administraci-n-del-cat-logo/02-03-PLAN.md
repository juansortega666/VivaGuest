2. **Cero objetos `Date`.** El `DTEND` se extrae como cadena `YYYYMMDD` cruda del `DTEND;VALUE=DATE:` y se devuelve como `'YYYY-MM-DD'`. La comparación con `hoyIso` es comparación de cadenas, que para el formato ISO es equivalente a comparación de fechas. 3. **Unfolding antes de parsear.** `desdoblar()` implementa RFC 5545 §3.1: normaliza `\r\n` a `\n` y elimina los saltos seguidos de espacio o tabulador. Sin esto, la `DESCRIPTION` de Airbnb viene partida a 75 octetos y la regex de `Reservation URL` no matchea, y el conteo da 0.

4. **Sniff antes de contar.** Si el cuerpo no contiene `BEGIN:VCALENDAR`, devolver `{ok:false, motivo:'no-es-ical'}` sin recorrer nada. Es el modo de falla más peligroso de la pantalla: un feed muerto devuelve HTTP 200 con HTML de error, y sin el sniff el escáner reporta "0 reservas" y el admin guarda un link roto creyendo que sirve.
